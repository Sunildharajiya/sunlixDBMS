# sunlixDBMS
SunlixDBMS is a custom database management system built from scratch in C. The project focuses on understanding how a DBMS works internally rather than relying on existing database engines or SQL.
The system uses JSON for data storage and provides its own command-line interface for interacting with data.

## Current Focus
- Custom CLI
- JSON-based data storage
- CRUD architecture
- File handling in C
- cJSON integration
- Modular DBMS structure

______________
SunlixDBMS is a learning-focused project that will gradually evolve into a more capable database engine while exploring concepts such as data management, indexing, searching, memory management, and performance.
